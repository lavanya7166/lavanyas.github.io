# Portfolio Website

A modern, responsive portfolio website template built with HTML, CSS, and JavaScript.

## Features

- 🎨 **Modern Design**: Clean and professional design with gradient accents
- 📱 **Fully Responsive**: Works seamlessly on desktop, tablet, and mobile devices
- ⚡ **Smooth Animations**: Engaging scroll animations and transitions
- 🎯 **Easy to Customize**: Simple structure makes it easy to add your own content
- 🚀 **Fast Loading**: Lightweight and optimized for performance

## Sections

1. **Hero Section**: Eye-catching introduction with animated background
2. **About**: Personal information and statistics
3. **Skills**: Showcase your technical skills and expertise
4. **Portfolio**: Display your projects with the ability to add new ones dynamically
5. **Contact**: Contact form and information

## Getting Started

1. Open `index.html` in your web browser
2. Customize the content with your own information:
   - Update name, title, and description in the hero section
   - Add your skills in the skills section
   - Update contact information
   - Add your social media links

## Customization

### Adding Portfolio Projects

You can add projects in two ways:

1. **Manually**: Edit the HTML in the portfolio section
2. **Dynamically**: Click the "Add New Project" button and fill in the prompts

### Changing Colors

Edit the CSS variables in `styles.css`:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    --accent-color: #ec4899;
    /* ... */
}
```

### Updating Contact Information

Edit the contact section in `index.html`:

```html
<div class="contact-item">
    <div class="contact-icon">...</div>
    <div>
        <h4>Email</h4>
        <p>your.email@example.com</p>
    </div>
</div>
```
